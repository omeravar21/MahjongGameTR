# CORE GAMEPLAY LOOP

Player selects a valid tile.

↓

Tile moves to tray.

↓

Matching occurs only inside tray.

↓

Two identical tiles match and disappear.

↓

Clear all board tiles to win.

↓

Advance to next level.

# TIMER SYSTEM

Every level uses a recommended timer generated by DifficultyDirector.

---

The timer scales with board complexity.

---

The timer is not fixed globally.

---

If timer reaches zero:

Level fails.

---

Player repeats the same level.

---

# LEVEL FAILURE RULES

A level fails if:

Tray reaches capacity without a valid match.

OR

Timer reaches zero.

---

# LEVEL COMPLETION RULE

A level completes when:

All board tiles are cleared.

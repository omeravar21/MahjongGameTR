DESIGN_BIBLE.md
PART 1 — VISUAL PHILOSOPHY & PLAYER FEEL
DESIGN GOAL

The game should feel:

Premium
Relaxing
Clean
Readable
Timeless

The visual design should create a calm and satisfying experience.

The player should never feel visually overwhelmed.

DESIGN IDENTITY

The game is NOT:

Cartoon
Toy-like
Neon
Flashy
Chaotic
Hyper Casual

The game IS:

Premium Casual
Elegant
Warm
Meditative
Modern
Refined
PLAYER FEELING

The player should feel:

Relaxed
Comfortable
Focused
Rewarded

The game should create:

Calm Competition

The game should not create stress through visuals.

VISUAL PRIORITY ORDER

Priority 1:

Readability

Priority 2:

Comfort

Priority 3:

Premium Feel

Priority 4:

Visual Variety

Priority 5:

Visual Complexity

If readability conflicts with aesthetics:

Readability wins.

VISUAL DESIGN PILLARS
Pillar 1 — Readability First

Players must instantly understand:

Selectable tiles
Tile layers
Board shape
Progress

The board must remain readable at all times.

Pillar 2 — Premium Materials

The game should feel crafted.

Materials should resemble:

Wood
Bamboo
Polished natural surfaces

Avoid:

Plastic feeling
Cheap mobile game look
Bright toy aesthetics
Pillar 3 — Calm Atmosphere

The visual style should feel:

Soft
Warm
Balanced
Comfortable

Avoid visual aggression.

Pillar 4 — Consistency

All UI elements should follow the same visual language.

Buttons

Panels

Tiles

Menus

Transitions

must feel part of the same product.

Pillar 5 — Timeless Design

The game should still look attractive years later.

Avoid trendy design choices that age quickly.

COLOR PHILOSOPHY

Primary Direction:

Warm Natural Colors

Preferred Materials:

Walnut Wood
Oak Wood
Bamboo
Soft Stone
Brushed Gold

Avoid:

Neon Colors
Extreme Saturation
High Contrast RGB Effects
LIGHTING PHILOSOPHY

Lighting should feel:

Soft
Natural
Warm

Avoid:

Harsh Glow
Excessive Bloom
Aggressive Lighting

The board should always remain readable.

BOARD VISUAL PHILOSOPHY

The board is the center of the experience.

Goals:

Immediate readability
Clear depth perception
Strong tile visibility
Comfortable long-term viewing

The board should feel organized rather than chaotic.

CAMERA PHILOSOPHY

Portrait orientation only.

Camera should:

Present the board clearly
Avoid dramatic angles
Prioritize readability

The player should never fight the camera.

TILE DESIGN PHILOSOPHY

Tiles are the most important visual element.

Tiles should feel:

Premium
Solid
Valuable
Readable

Tiles should never feel:

Cheap
Flat
Plastic
TILE SHAPE PHILOSOPHY

Preferred Shape:

Classic Mahjong Inspired

Characteristics:

Rounded corners
Slight thickness
Soft bevels
Premium proportions

Avoid:

Sharp edges
Thin flat cards
Overly stylized shapes
TILE READABILITY RULE

A player should recognize tile symbols instantly.

Symbol clarity is more important than decorative detail.

The symbol should remain readable even on smaller devices.

END OF DESIGN_BIBLE.md PART 1

PART 2 — TILE DESIGN SYSTEM
TILE DESIGN PHILOSOPHY

Tiles are the most important visual element in the entire game.

The player spends most of their time looking at tiles.

Tile design must prioritize:

Readability
Comfort
Premium Feel
Layer Recognition

Decorative complexity is always secondary.

TILE THICKNESS

Official Direction:

Medium Thickness

Specification:

Tile Thickness = 12–15% of Tile Width

Characteristics:

Premium
Balanced
Easy to Read
Comfortable

Avoid:

Thin card-like tiles
Extremely thick tiles
Exaggerated depth

Goal:

Create a premium Mahjong-inspired appearance while maintaining board readability.

TILE SHADOW SYSTEM

Official Direction:

Medium Shadow Strength

Characteristics:

Soft
Natural
Clean
Readable

Purpose:

Improve depth perception
Improve layer readability
Improve board clarity

Avoid:

Heavy dark shadows
Aggressive shadows
Visual clutter
LAYER SHADOW SCALING

Layer 1:

100%

Layer 2:

80%

Layer 3:

60%

Layer 4:

40%

Goal:

Create depth while preserving readability.

TILE BEVEL SYSTEM

Official Direction:

Soft Bevel

Characteristics:

Smooth transitions
Premium appearance
Soft highlights
Natural edges

Avoid:

Hard bevels
Sharp metallic edges
Aggressive highlights

Goal:

Tiles should feel refined rather than mechanical.

TILE MATERIAL PHILOSOPHY

Official Material Direction:

Ivory Stone / Porcelain Feel

Visual Characteristics:

Slightly warm
Soft surface
Premium texture
Natural appearance

Avoid:

Plastic materials
Toy-like surfaces
Cheap glossy finishes

Goal:

Tiles should feel valuable and timeless.

TILE CORNER DESIGN

Corner Style:

Rounded Corners

Characteristics:

Soft
Friendly
Premium
Comfortable

Avoid:

Sharp corners
Hard geometric appearance
TILE FACE DESIGN

Primary Rule:

Symbol > Decoration

The symbol is always the most important visual element.

Decorations must never compete with symbols.

Goal:

Instant recognition.

SYMBOL SIZE RULE

Symbol Coverage:

55–65% of Tile Face

Characteristics:

Large
Readable
Recognizable

Goal:

Maintain readability across all supported devices.

SYMBOL DESIGN PHILOSOPHY

Symbols should be:

Simple
Clean
Distinct
Easy to recognize

Avoid:

Overly detailed icons
Tiny decorative elements
Excessive visual noise
TILE COLOR PHILOSOPHY

Base Tile Color:

Warm Ivory

Accent Colors:

Theme Dependent

Goal:

Maintain readability regardless of theme selection.

TILE STATE VISIBILITY RULE

Selectable and non-selectable tiles should not dramatically change appearance.

Avoid:

Glow outlines
Bright highlights
Strong color shifts

Reason:

Players should learn board structure naturally.

LAYER VISUAL STYLE

Official Style:

Compact Premium Stack

Characteristics:

Organized
Structured
Elegant
Readable

Goal:

The board should feel crafted rather than random.

GRID ALIGNMENT RULE

All tiles remain aligned to the base grid.

Applies To:

Base Layer
Upper Layers
Closed Tiles
Joker Tiles

Rules:

No random offsets
No floating tiles
No chaotic placement
DEPTH PERCEPTION RULE

Players must instantly understand:

Which tile is above
Which tile is below
Which tile is blocking another tile

Depth communication is more important than visual decoration.

TILE VISUAL PRIORITY ORDER

Priority 1:

Readability

Priority 2:

Depth Perception

Priority 3:

Comfort

Priority 4:

Premium Feel

Priority 5:

Visual Decoration

If priorities conflict:

Higher priority wins.

BOARD PRESENTATION PHILOSOPHY

The board should feel:

Organized
Calm
Premium
Understandable

The player should immediately understand the board structure without effort.

FINAL TILE DESIGN PRINCIPLE

The player should never struggle to understand the board.

The player should feel that every tile is:

Premium
Valuable
Readable
Comfortable to interact with

Readability always wins over decoration.

END OF DESIGN_BIBLE.md PART 2

PART 4 — UI DESIGN SYSTEM
UI DESIGN PHILOSOPHY

The UI should feel:

Premium
Minimal
Elegant
Readable
Calm

The UI must support gameplay.

The UI must never compete with gameplay.

CORE UI PRINCIPLE

Large Targets

Minimal Interface

Premium Presentation

ONE PRIMARY ACTION RULE

Every screen must have one dominant action.

Examples:

Main Menu

↓

Level Button

Performance Screen

↓

Next Level Button

Lose Screen

↓

Retry Button

Settings Screen

↓

Back Button

The player should never wonder what to do next.

UI COMPLEXITY RULE

Maximum Clarity

Minimum Clutter

Avoid:

Too many buttons
Too many notifications
Too many currencies
Too many menus
Too many popups
MAIN MENU PHILOSOPHY

The Main Menu is the player's home.

The player should immediately understand:

Current Level
Play Button
Ranking
Theme Selection
Settings

No additional distractions.

MAIN MENU LAYOUT

Center:

Large Level Button

Top Area:

Theme Selection
Tile Set Selection
Settings

Additional Access:

Ranking
Statistics
LEVEL BUTTON PHILOSOPHY

The Level Button is the most important UI element.

The button should:

Be large
Be obvious
Display current level

Example:

LEVEL 245

Tap to Play

GAMEPLAY HUD PHILOSOPHY

The board is the hero.

HUD exists only to support gameplay.

GAMEPLAY HUD LAYOUT

Top Area:

Timer
Score

Upper Area:

Tray

Center:

Board

Bottom Area:

Shuffle
Undo
Hint
BOOSTER BUTTON RULE

Booster buttons must be:

Easy to access
Easy to understand
Visually consistent

Avoid oversized booster buttons.

PERFORMANCE SCREEN PHILOSOPHY

The screen should celebrate achievement.

The player should immediately see:

Completion Time
Score
Combo Count
Highest Combo
Next Level Button
PERFORMANCE SCREEN PRIORITY

Priority 1:

Final Score

Priority 2:

Completion Time

Priority 3:

Combo Statistics

Priority 4:

Next Level Button

RANKING SCREEN PHILOSOPHY

The ranking screen should motivate improvement.

The player should immediately understand:

Current Rank
Highest Rank
Total Score
Progress
SETTINGS SCREEN PHILOSOPHY

Settings should remain simple.

Launch Settings:

Music Volume
SFX Volume
Vibration
Language
PANEL DESIGN PHILOSOPHY

Panels should feel:

Premium
Soft
Elegant

Avoid:

Heavy borders
Aggressive shadows
Neon effects
BUTTON DESIGN PHILOSOPHY

Buttons should feel:

Responsive
Comfortable
Premium

Avoid:

Tiny buttons
Flashing buttons
Aggressive animations
FINAL UI PRINCIPLE

The player should always know:

Where they are
What they achieved
What to do next

UI clarity is more important than UI decoration.

PART 5 — ANIMATION & AUDIO PHILOSOPHY
ANIMATION PHILOSOPHY

The game should feel:

Smooth
Premium
Responsive
Relaxing

Never:

Chaotic
Hyperactive
Aggressive
ANIMATION PRIORITY ORDER
Readability
Feedback
Comfort
Premium Feel
Visual Flair
TILE MOVEMENT PHILOSOPHY

Tile movement should feel:

Natural
Controlled
Precise

The player should always understand:

Where the tile came from
Where the tile is going
TILE TO TRAY ANIMATION

Target Duration:

0.25 – 0.35 seconds

Recommended:

0.30 seconds

Animation Style:

Smooth Ease Out

Avoid:

Bouncy
Cartoonish
Elastic
MATCH ANIMATION

Match Delay:

0.30 seconds

Sequence:

Tile Match

↓

Match VFX

↓

Tile Shatter

↓

Cleanup

Total Duration:

0.45 – 0.60 seconds

BUTTON ANIMATION

Button Scale:

95% → 100%

Duration:

0.08 – 0.12 seconds

Goal:

Immediate feedback

DOOR ANIMATION

The door is the signature transition.

Goal:

Premium
Memorable
Cinematic

Duration:

0.75 – 1.25 seconds

Recommended:

1.0 second

PERFORMANCE SCREEN ANIMATION

Information should appear gradually.

Order:

Completion Time
Score
Combo Count
Highest Combo
Next Level Button
VFX PHILOSOPHY

Effects support gameplay.

Effects never dominate gameplay.

Priority:

Readability
Feedback
Satisfaction
MATCH VFX

Style:

Clean
Premium
Fast

Avoid:

Huge explosions
Full screen effects
Visual clutter
JOKER VFX

Joker effects may be stronger than standard match effects.

Goal:

Special
Rewarding
Noticeable
WIN VFX

Goal:

Celebration
Achievement
Progress

Not:

Overstimulation
LOSE VFX

Goal:

Clear Feedback
Immediate Retry Motivation

Player should feel:

Try Again

Not:

Failure

AUDIO PHILOSOPHY

Audio should feel:

Warm
Relaxing
Premium
Meditative
MUSIC PHILOSOPHY

Music should support focus.

Characteristics:

Soft
Ambient
Organic
Calm

Inspirations:

Nature
Wood
Zen
Premium Lounge

Every sound must have purpose.

Important Sounds:

Tile Select
Tile Move
Match
Combo
Joker
Win
Lose
Button Click
HAPTIC PHILOSOPHY

Use haptics sparingly.

Recommended Events:

Match
Combo
Joker
Win

Avoid:

Constant vibration
Menu vibration spam
FINAL ANIMATION & AUDIO PRINCIPLE

Every animation should improve clarity.

Every sound should improve feedback.

Nothing should distract from the board.
